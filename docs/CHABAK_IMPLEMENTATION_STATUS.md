# CHABAK 구현 현황

기준일 2026-11-07. 화면과 SDK는 최신 Android APK로 실행 검증하지 못했다.

| 영역 | 현재 구현 | 남은 검증 또는 구현 |
| --- | --- | --- |
| 홈·여행 | 자연 배경 4종, 반투명 카드, 홈 네 메뉴, 여행 선택 | 버튼 가림, 뒤로 가기, 화면 회전·복원 |
| 장소 탐색 | 고캠핑 검색·추천, 시설·예약 정보, 샤워실 필수 필터, 추천 근거와 최대 5곳 | 인증 상태가 일치하는 공식 API 재조회, Android 표시 비교, 인원·숙박·숙련도 기반 순위 |
| 노지·공공 | 허용 기간, 관리기관 출처, 접근·야간 주차·차량 숙박·화기 조건 검증 | 허용 자료 0건. 관리기관 증빙 수집 |
| 준비물·SQLite | 여행별 계절·인원·숙박·시설에 따른 준비물, 필수·추천·현장 확인·직접 추가 표시, tripId 저장 | 방문일 예보, 숙련도 기반 항목, 여행 A/B와 마이그레이션 실행 |
| 이동 | NaviHelper 3.0.5, 방향별 계획, 휴게소 연결 후보 구조 | Pleos 목적지·거리·시간·완료 이벤트와 진입 방향별 링크 검증 |
| 에너지 | Vehicle SDK 2.3.2 읽기, 숙박 추정, 화면 잔량 경고와 별도 수동 시뮬레이션 | 실시간 SDK, 백그라운드 알림과 귀가 에너지 근거 |
| 휴식 | 자연음 4종과 스마트 모닝. 차량 조작 제한 시 일출 화면 억제 | 오디오 충돌, 날짜 예약 UX, 재부팅·시간대 변경, Pleos 전환 확인 |
| Gleo | 스키마, 인텐트 및 콜백 | 최신 APK Cold/Warm ADB, 음성 발화, 스키마 승인·마켓 상태 |
| 지역 경험 | 범위와 데이터 신뢰 기준 검토 | P0 해결 후 공식 데이터 확보와 설계 착수 |

- Kotlin 직접 컴파일과 JVM 단위 테스트를 통과했다. Pleos 에뮬레이터·실차에서 확인된 항목은 이번 작업에 없다.
- 8085에서 조건에 맞는 5건 응답을 관측했다. 키가 제거된 서버 프로세스의 상태와 8085 응답이 일치하지 않아 공식 조회 성공으로 분류하지 않았다.
