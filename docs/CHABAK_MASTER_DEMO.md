# CHABAK 시연 및 발표 안내

CHABAK은 차량 화면에서 캠핑장 탐색부터 준비, 이동, 주차 후 휴식, 기상, 여행 기록까지 연결하는 Pleos Connect용 앱이다. 고캠핑 데이터로 장소와 시설을 확인하고 NaviHelper에 목적지를 전달한다. 여행 상태와 사용자 기록은 SQLite에서 tripId별로 분리된다.

## 3–5분 시연

1. Pleos API 34에서 CHABAK을 열고 홈 네 메뉴를 보여준다. 8085 상태와 현재 사용자, 알림 권한을 미리 확인한다.
2. 차박지 찾기에서 경기·숲 조건으로 추천한다. 공식 등록 시설과 차량 내 숙박·EV 충전 확인 필요 상태를 보여준다. 캠핑장을 선택하고 준비물 하나를 체크한다.
3. 이동 정보에서 Pleos 내비 목적지 설정을 요청한다. 내비 화면에 해당 목적지가 나타나면 보여준다. 안내를 종료하고 CHABAK으로 돌아온다.
4. 주차 상태에서 차박 시작을 누른다. 환경 화면에서 시간대와 규칙 기반 추천 이유를 보여주고 자연음 한 종류를 직접 재생한 뒤 중지한다.
5. 스마트 에너지에서 Vehicle SDK 응답과 사용자가 저장한 보호 기준을 보여준다. 예약 시간이 지연될 수 있는 대체 알람은 화면에 표시된 제한과 함께 설명한다.
6. 차박 종료 후 여행 기록에서 시작·종료 시각과 테스트 메모·사진을 확인한다. 앱을 다시 열어 동일한 여행의 기록을 보여준다. 개인 사진이나 기록을 선택할 필요 없이 검증용 단색 PNG를 사용할 수 있다.

## 구현 구조

| 흐름 | 역할 |
| --- | --- |
| 한국관광공사 고캠핑 → Python 8085 | 공식 목록 정규화, 검색, 규칙 기반 최대 5곳 추천, 좌표와 확인 필요 항목 반환 |
| Open-Meteo → Compose | 공개 캠핑장 인근 또는 지역 대표지점의 현재 기상 모델, 모델 시각과 조회 시각 |
| Compose → SQLite | 캠핑장·준비물·내비 계획·보호 기준·모닝·다이어리를 여행별 저장 |
| CHABAK → NaviHelper 3.0.5 | 목적지 요청, 좌표 일치 및 경로 안내 확인 |
| Vehicle SDK 2.3.2 → CHABAK | 에뮬레이터 SoC·공칭 용량과 조명 Capability 조회 |
| AAOS → 조작 조건 | 휴식·다이어리 등 주차용 화면 조작 상태 확인 |

## 심사 질문

| 질문 | 설명 |
| --- | --- |
| 일반 캠핑 앱과 차이가 있나 | 목적지 전달 후 차량용 화면의 배터리 확인, 휴식, 기상, 기록으로 이어진다. |
| AI는 어디에 쓰이나 | 캠핑장 순위와 환경 추천은 등록 시설, 자연환경, 계절, 시각, 날씨에 따른 규칙이다. 모델 학습이나 취향 학습을 사용하지 않는다. |
| 배터리 수치의 범위는 | API 34 에뮬레이터 SDK 반환값이다. 보호 기준을 뺀 가용 비율을 표시하며 소비전력이 확인되지 않으면 시간 계산을 제한한다. |
| 내비 연동의 근거는 | NaviHelper의 목적지 일치와 ROUTE_GUIDING을 확인했다. 도착 후에는 사용자가 직접 차박을 시작한다. |
| 주행 안전은 어떻게 처리하나 | AAOS 조작 제한을 확인한다. 자연음은 사용자가 재생한다. 차량 조명은 Capability 조회까지만 연결한다. |
| 실차와 상용화 상태는 | 차량 모델별 SDK 권한, 실제 차량 정차·주행·내비 도착, 운영용 HTTPS, 데이터 제공 조건을 별도 검증해야 한다. |

## 캡처와 녹화

ADB 캡처는 Pleos 화면에서 직접 확보한다. 기기에서 녹화하려면 다음 명령을 순서대로 사용한다. 180초 이내에 홈 → 추천 → 이동 → 차박 중 → 에너지 → 환경 → 모닝 → 다이어리를 보여준다. 개인 데이터 화면은 검증용 여행으로 대체한다.

```powershell
adb -s emulator-5554 shell screenrecord --time-limit 180 /data/local/tmp/chabak-demo.mp4
adb -s emulator-5554 pull /data/local/tmp/chabak-demo.mp4 .
```

공모전의 규정 및 제출 형식은 주최 측 기준 확인 후 결정한다.

첨부한 32초 영상은 에뮬레이터의 검증용 여행에서 여행 기록, 사진 확대, 스마트 에너지 화면을 확인한 짧은 클립이다. 전체 3–5분 발표는 위 순서를 사용한다.
