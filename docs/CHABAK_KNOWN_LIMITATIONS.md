# CHABAK 제한사항

- 2026-11-09 자체 AI를 제거한 Debug APK 생성과 Pleos 에뮬레이터 실행을 확인했다. 현재 Android 53개 테스트가 통과했다. 실차 검증은 수행하지 않았다. [최신 Gleo 구성 보고](CHABAK_GLEO_ONLY.md)
- Gleo 세 Action의 Cold/Warm Intent와 앱 Broadcast Callback은 확인했다. 실제 발화·Gleo 수신·응답 음성, 스키마 승인·App Market 등록은 미검증이다. 앱 접수 후 6초 기한을 적용하며 느린 조회는 음성 요청을 실패 처리한다. [Gleo 콜백 문서](https://document.pleos.ai/docs/pleos-only/app-integration-guide/guide/action_callback)
- 자체 STT/TTS·LLM 대화 서버는 방향 수정으로 제거했다. 과거 Speech SDK 오류는 현재 앱 구성의 의존 문제가 아니다. Gleo는 등록된 Action만 앱에 전달하며 CHABAK 음악·스마트 모닝·차량 조명 제어는 현재 스키마에 노출하지 않았다.
- 실제 차량 배터리 지원과 권한은 차량·서비스 환경에 따라 확인해야 한다. 최소 보존 잔량 대비 추정은 귀가에 필요한 에너지 판정과 별개다. 잔량 경고는 화면에 표시되며 백그라운드 전달을 보장하지 않는다.
- 노지 허용 기록은 0건이다. 일반 야영장 등록, EV 충전, 차량 내 숙박, 주차와 취사는 서로 독립적으로 확인해야 한다.
- 방향별 실제 도로 링크가 없으면 경로상 휴게소를 확정하지 않는다. 음식 API의 인증과 이전 거절 원인은 확인되지 않았다.
- 고캠핑 서버 프로세스에 인증키가 필요하다. 2026-11-09 기존 8085 서버의 고캠핑 출처 응답과 Intent 조건에 맞는 5곳의 앱 표시를 확인했다. `10.0.2.2`는 에뮬레이터 개발 서버 주소이므로 실차 배포 환경은 별도 구성해야 한다. 예보 대신 관측만 있는 경우 준비물에서 현재 관측으로 표시한다.
- 스마트 모닝의 날짜 직접 선택, 시간대 변경, 재부팅 복원과 앱 전환 중 재생은 기기 재검증이 필요하다. 대체 알람은 지연될 수 있다.
