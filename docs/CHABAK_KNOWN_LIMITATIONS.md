# CHABAK 제한사항

- 이 세션에서 최신 APK 생성과 실차·Pleos 에뮬레이터 실행을 확인하지 못했다. 기존 APK를 최신 시연으로 사용하지 않는다.
- Gleo 실제 발화에 사용할 마이크가 없다. 최신 APK의 ADB 호출, 스키마 승인, App Market 등록도 확인되지 않았다. Gleo 문서의 7초 제한과 현재 추천 연결 시간의 차이는 기기 검증이 필요하다. [Gleo 콜백 문서](https://document.pleos.ai/docs/pleos-only/app-integration-guide/guide/action_callback)
- 실제 차량 배터리 지원과 권한은 차량·서비스 환경에 따라 확인해야 한다. 최소 보존 잔량 대비 추정은 귀가에 필요한 에너지 판정과 별개다. 잔량 경고는 화면에 표시되며 백그라운드 전달을 보장하지 않는다.
- 노지 허용 기록은 0건이다. 일반 야영장 등록, EV 충전, 차량 내 숙박, 주차와 취사는 서로 독립적으로 확인해야 한다.
- 방향별 실제 도로 링크가 없으면 경로상 휴게소를 확정하지 않는다. 음식 API의 인증과 이전 거절 원인은 확인되지 않았다.
- 고캠핑 서버 프로세스에 인증키가 필요하다. 이번 8085 관측 응답의 출처는 재확인이 필요하다. 예보 대신 관측만 있는 경우 준비물에서 현재 관측으로 표시한다.
- 스마트 모닝의 날짜 직접 선택, 시간대 변경, 재부팅 복원과 앱 전환 중 재생은 기기 재검증이 필요하다. 대체 알람은 지연될 수 있다.
