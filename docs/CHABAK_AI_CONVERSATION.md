# 철회된 CHABAK 자체 AI 대화 설계

2026-11-09 사용자 방향 수정에 따라 이 설계의 캐릭터 버튼·대화 창·자체 STT/TTS·LLM 서버·세션 코드를 제거했다. 이 기능은 현재 앱에서 사용하지 않는다.

현재 음성 AI는 Gleo이며, 기존 Action 3개를 통해 CHABAK 기능을 호출하고 공식 Callback으로 응답한다. 실제 Gleo 발화 연동 여부는 Intent 테스트와 구분한다.

현재 파일 목록·검증 결과·실행 절차는 [Gleo 단일 음성 AI 보고서](CHABAK_GLEO_ONLY.md)를 참조한다. 과거 자체 음성 진단 자료를 현재 앱의 성공 근거로 사용하지 않는다.
